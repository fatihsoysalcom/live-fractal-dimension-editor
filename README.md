# Live Fractal Dimension Editor

This example demonstrates an interactive fractal explorer, simulating aspects of a 'Live Holographic Editor' and 'Fractal Time'. Users can pan and zoom into the Mandelbrot set, experiencing immediate visual feedback akin to live editing in a complex, multi-dimensional space. Adjusting the 'Max Iterations' slider illustrates the concept of 'Fractal Time' by revealing deeper layers of detail, similar to refining a project over temporal dimensions.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any modern web browser.
